# My First Portfolio Website

This is my first portfolio website and one of my first projects as I start learning web development.

I created this project to practice the basics of building a website and to get more comfortable using tools such as Visual Studio Code, Git, and GitHub. It is also the beginning of a portfolio where I can document and showcase the projects I build as I continue learning.

## About the Project

The website is a simple personal portfolio. It is intended to introduce me, show some of my skills and interests, and eventually provide a place where I can showcase the projects I work on.

The website is still at an early stage, and I expect it to change a lot as I learn more about web development.
